# Design System

## Colors

| Token | Hex | Usage |
|---|---|---|
| Moss | `#142012` | Dark section / hero / tea houses |
| Deep leaf | `#20301c` | CTA / text emphasis |
| Matcha | `#9eb45d` | Accent / progress / active state |
| Pale matcha | `#c9d88f` | Highlight text |
| Washi | `#f3eddc` | Main warm neutral background |
| Ivory | `#f7f2e7` | Main light text |
| Hojicha | `#aa7952` | Hojicha section |

## Typography

Starter không phụ thuộc Google Fonts để build offline ổn định.

- Display: Georgia / Times New Roman fallback.
- UI/body: Aptos / Segoe UI / Arial.
- Display tracking: khoảng `-0.04em` đến `-0.065em`.
- Kicker: uppercase + tracking rộng.

## Spacing

Dựa trên nhịp 8px. Section desktop thường 128–160px; mobile 96px.

## Radius

- Card lớn: 32–40px.
- Card nhỏ: 20–24px.
- CTA: pill / 999px.
