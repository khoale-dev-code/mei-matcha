# Project Skills

These files describe the engineering and UI rules applied to this starter.

- `project-rules.md` — local source of truth
- `senior-frontend.md` — architecture / clean code / performance
- `ui-design-system.md` — visual consistency / responsive / accessibility
- `react-best-practices.md` — React + Next rendering/performance rules

If you also use Claude Code locally, the external skill referenced during project setup can be installed with:

```powershell
npx claude-code-templates@latest --skill web-development/react-best-practices
```

The project remains runnable without that external skill; it is guidance for the coding agent, not a runtime dependency.
