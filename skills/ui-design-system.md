# UI Design System Skill — Applied

## Tokens

Use CSS/Tailwind theme tokens instead of magic values when a value is reused.

Core semantic palette:
- matcha
- moss
- ivory
- washi
- hojicha   

## Components

- Display heading
- Section kicker
- Primary/secondary pill CTA
- Tea profile card
- Large media card
- Floating header

## Responsive handoff

Every major component should document behavior at mobile/tablet/desktop. Avoid animation that requires pointer hover to understand content.

## Accessibility

- Contrast and focus visibility.
- Semantic landmarks.
- 44px touch targets.
- reduced motion.
- meaningful alt text for content imagery.
